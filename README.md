Zach Kennedy – Portfolio

A responsive, HTML/CSS-based personal portfolio website showcasing my background, goals, and interests. Built as part of CPSC 24700 web programming coursework and deployed as an Azure static site.

PROJECT OVERVIEW
This repository contains the source files for my personal portfolio website. It was created to demonstrate proficiency in:
- HTML5 semantics and structure
- External CSS (Flexbox layout, responsive design)
- Styled tables and navigation menus
- Responsive breakpoints for mobile and desktop viewing
- Version control with Git & GitHub
- Deployment to Azure Static Web Apps

The portfolio includes:

- A header with name, contact links, and profile image
- A navigation bar linking to each section
- Four main content sections:
    - Introduction
    - Course Goals (displayed in a styled table)
    - Hobbies (hyperlinked list)
    - Fun Fact
- A footer with copyright information
